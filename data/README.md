# Bio-Quantum Eigenmodes: Healthy Brainwave Signatures for Therapeutic Entrainment

Synthetic EEG datasets representing 7 clinical neurological conditions, generated by
[taurus-gcfd-tracker](https://github.com/Taurus-Ai-Corp/taurus-gcfd-tracker).

## What This Dataset Contains

Each CSV file is a 10-second, single-channel synthetic EEG signal at 250 Hz (2,500 samples)
with physiologically grounded signal composition:

- **Theta oscillations** (4-8 Hz) — long-range neural communication
- **Gamma oscillations** (30-100 Hz) — local processing, phase-amplitude coupled to theta
- **Alpha background** (10 Hz) — resting-state activity
- **1/f pink noise** — biologically realistic spectral profile
- **60 Hz line noise** — environmental artifact

### Columns

| Column | Unit | Description |
|--------|------|-------------|
| `time_s` | seconds | Time axis |
| `eeg_uv` | microvolts (arbitrary) | Raw composite EEG signal |
| `theta_filtered` | a.u. | Bandpass-filtered theta component (4-8 Hz) |
| `gamma_filtered` | a.u. | Bandpass-filtered gamma component (30-100 Hz) |
| `theta_phase_rad` | radians | Instantaneous theta phase (Hilbert transform) |
| `gamma_phase_rad` | radians | Instantaneous gamma phase (Hilbert transform) |

## Usage

```python
import pandas as pd
from taurus_gcfd import CoherenceTracker

df = pd.read_csv("healthy_adult.csv")
tracker = CoherenceTracker(sampling_rate=250)
score = tracker.calculate_global_coherence(df["eeg_uv"].values)
print(f"Coherence: {score:.3f}")
```
