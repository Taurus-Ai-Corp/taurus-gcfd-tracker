## Angles to Mention

### AI Assist Program (CAD 100M NRC Pool)
NRC announced a $100M/year AI program for 2025–2026. Our project uses signal processing algorithms that map to AI/ML — mention this explicitly. Ask if GCFD qualifies under the AI Assist stream.

### Youth Employment Program (YEP) Stacking
IRAP has a separate Youth Employment Program that subsidizes hiring graduates (under 30). If we plan to hire a Mitacs intern who then converts to a full-time role, YEP could cover additional salary costs. Ask about stacking YEP with the main IRAP contribution.

### Open-Source + Commercial Model
Emphasize that the open-source core drives adoption (community, citations, trust) while the commercial layer (API, enterprise licenses, clinical presets) generates revenue. This is a proven business model (Red Hat, Elastic, Databricks). IRAP likes clear paths to revenue.
